# MOODD Admin — Template

Motore admin per ristoranti (Astro SSR + Supabase + Stripe + Resend):
commandes, réservations con plan de salle, clients CRM, menu + lunch,
statistiques, marketing (pop-up, newsletter con segmenti e programmate,
coupons), assets, documents con scadenze contratti, permessi per pagina e tab.

**Questo repo è il TEMPLATE**: la fonte della verità del motore. Ogni cliente
è un repo separato creato da qui con la storia git condivisa.

- **Setup di un nuovo cliente e aggiornamenti** → [`SETUP.md`](SETUP.md)
- **Architettura del motore** → [`ENGINE.md`](ENGINE.md)
- **Migrazioni database (in ordine)** → [`supabase/MIGRATIONS.md`](supabase/MIGRATIONS.md)
